Stash Minimal · {{VERSION}}

A quieter library.

A minimal dark theme for Stash. Neutral surfaces, compact controls, and locally bundled Geist Sans. CSS only, with your existing Stash controls.

Source on GitHubDownload theme

Install in Stash

  1. Open Settings → Plugins → Available Plugins → Add Source.
  2. Name it Stash Minimal and paste the source URL below.
  3. Install Stash Minimal, disable your previous theme, and reload.
